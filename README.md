# book-hunter 📚

כלי שבודק כל 3 שעות אם ספרים מהרשימה שלך הגיעו לחנויות יד שנייה, ופותח **Issue** במאגר ב-GitHub על כל עותק **חדש**.
כרגע הוא בודק את **גולדמונד ספרים (חיפה)**. אפשר להוסיף אתרים נוספים בהמשך.

## איך זה עובד

1. פעם ב-3 שעות GitHub Actions מריץ את `hunter.py`.
2. הסקריפט מוריד את כל הקטלוג של גולדמונד (קובץ JSON אחד) ומשווה אותו לרשימה ב-`books.csv`.
3. ההתאמה סלחנית להבדלים קטנים: `A Clash of Kings` תואם גם ל-`Clash of Kings: Book Two`,
   ו-`Harlan Coben` תואם ל-`Coben, Harlan`. אבל `Dune` **לא** יתאים ל-`Dune Messiah`.
4. כשנמצאים עותקים חדשים, נפתח Issue עם טבלה (כותר, מחבר, מחיר, מצב, איפה) ותיוג שלך,
   ו-GitHub שולח לך התראה.
5. עותקים שכבר דווחו נשמרים ב-`state.json`, כך שלא ייפתח Issue על אותו עותק פעמיים.
   בריצה הראשונה ייפתח Issue על כל מה שכבר נמצא בחנות.

## התקנה (פעם אחת, כ-5 דקות)

אין צורך בשום סיסמה או מפתח: הכלי משתמש בהרשאה המובנית של GitHub Actions.

### 1. ליצור מאגר ב-GitHub
צרי מאגר חדש, **פרטי** (Private), והעלי אליו את כל הקבצים בתיקייה, כולל התיקייה `.github`.

### 2. לוודא שההתראות יגיעו
- **בטלפון:** התקיני את אפליקציית GitHub (אנדרואיד או אייפון), התחברי,
  וב-Settings → Notifications ודאי שהתראות פוש מופעלות.
- **במאגר:** כפתור **Watch** למעלה צריך להיות על **All Activity**, או לפחות על **Participating and @mentions**.
  ה-Issue מתייג אותך, אז גם ההגדרה השנייה מספיקה.
- GitHub שולח את ההתראות גם במייל, לפי ההגדרות ב-https://github.com/settings/notifications

### 3. לבדוק שזה עובד
**Actions → book-hunter → Run workflow**. אחרי כחצי דקה הריצה צריכה להיות ירוקה,
ואם יש בחנות ספר מהרשימה, ייפתח Issue בלשונית **Issues**.

## אחרי שמגיעה התראה

נכנסים ל-Issue, רואים את הפרטים ומזמינים. אחרי שטיפלת, סוגרים את ה-Issue (**Close issue**),
כך שהלשונית Issues תציג רק ממצאים שעוד לא טופלו.

## עריכת רשימת הספרים

עורכים את `books.csv` ישירות באתר או באפליקציה של GitHub: לוחצים על הקובץ ואז על סמל העיפרון.

```csv
title,author,max_price
Mother Night,Kurt Vonnegut,
A Clash of Kings,George R.R. Martin,40
```

- `title`: שם הספר באנגלית (חובה).
- `author`: שם המחבר. לא חובה, אבל מאוד מומלץ, כי בלעדיו יש יותר התאמות שווא.
- `max_price`: מחיר מקסימלי (לא חובה). עותקים יקרים יותר לא ידווחו.

## הערות

- **מחירים:** בקטלוג של גולדמונד המחירים מופיעים עם ספרה אחרי הנקודה (למשל `25.4`).
  לא ברור מה היא מסמנת, ולכן ההתראה מציגה את המחיר בדיוק כפי שהוא בקטלוג. כדאי לבדוק מול החנות.
- **אין קישור ישיר לספר:** בקטלוג של גולדמונד אין דף לכל ספר, אז ההתראה מפנה לדף החיפוש שלהם.
- **הזמנה:** דרך העגלה בדף הקטלוג, או בטלפון 04-8622472 / ווטסאפ.
- **תקלה באתר:** אם הקטלוג לא נטען או נראה ריק, הריצה מדלגת עליו ולא מוחקת את מה שכבר דווח.
  אם הריצה נכשלת, GitHub שולח על כך מייל.
- **השבתה אוטומטית:** GitHub משבית ריצות מתוזמנות במאגר שלא היה בו שום שינוי 60 יום.
  כל עדכון של `state.json` או של רשימת הספרים נחשב שינוי. אם בכל זאת קיבלת מ-GitHub הודעה על השבתה,
  מפעילים מחדש בלשונית Actions.
- **עלות:** אפס. במאגר פרטי כל ריצה לוקחת פחות מדקה, הרבה מתחת למכסה החינמית של GitHub.

## בדיקה מקומית (לא חובה)

```bash
pip install -r requirements.txt pytest
python -m pytest -q
python hunter.py --dry-run      # מראה איזה Issue היה נפתח, בלי לפתוח ובלי לשמור
```
